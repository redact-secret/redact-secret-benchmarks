# Security policy

This repository measures secret-scanner output and publishes the results. It
does not ship a scanner. Report a vulnerability in its eval, CI or publish
pipeline through GitHub's private vulnerability reporting:
<https://github.com/redact-secret/redact-secret-benchmarks/security/advisories/new>.

Please do not open a public issue for an undisclosed vulnerability. Expect an
acknowledgement within 7 days. A detection gap in a scanned product is not a
vulnerability here; file it as a known-gap issue.
