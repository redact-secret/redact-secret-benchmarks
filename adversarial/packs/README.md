# Submitted packs

One directory per pack, named by its `id`, holding `intake.json` and — once
frozen — `first-run.json`. No externally authored pack has been submitted yet;
[#140](https://github.com/redact-secret/redact-secret-benchmarks/issues/140)
tracks the first one.
[`beta9-external-inputs`](beta9-external-inputs/README.md) is built from
externally authored public inputs, but the project assembled it, so it is
maintainer regression.
See [`../README.md`](../README.md) for the intake contract.
