# AI21

AI21 issues API keys in AI21 Studio (Settings, API Keys, "Create new key").
The provider documentation says the key is shown once, that only its last
characters are visible afterwards, and that anyone holding it can call the
API ([create an API key](https://docs.ai21.com/docs/create-api-key)). The
Python SDK reads `AI21_API_KEY` and sends `Authorization: Bearer`, with no
prefix, length or alphabet validation. Whether and how core detects a family
is not recorded here.

## Families

### `ai21:api-key` — API key (unprefixed)

- **Shape:** no prefix observed; 32 characters `[A-Za-z0-9]`, mixed case,
  recognised only beside a same-line AI21 name, host or SDK constructor.
  This is not provider-stated. It rests on 10 distinct literals from
  `AI21Client(api_key=...)` fragments in a public code search (n=10, values not
  retained), all exactly 32 alphanumeric with upper, lower and digit present.
- **Sources:** none. No provider page, staff statement or SDK code states a
  shape, and no scanner rule was found in trufflehog, gitleaks, betterleaks,
  noseyparker, secretlint or Kingfisher (path-name checks); GitHub has no
  AI21 row; GitGuardian coverage was not verified either way. The
  research called this T2 at best; the #774 close-out and the taxonomy record
  T0, which this dossier follows.
- **Issuance:** not attempted. The #784 checklist covers length, charset,
  fixed segments, case mix, the masked suffix shown afterwards, and a second
  workspace.
- **Collisions:** MD5 and other 32-character hashes, UUIDs without dashes,
  session ids, other vendors' 32-byte keys, and the non-secret `AI21_API_HOST`,
  `AI21_API_VERSION` and `AI21_AWS_REGION` variables.
- **Current contract in core:** [`detector-families.md`](https://github.com/redact-secret/redact-secret/blob/main/docs/specs/detector-families.md),
  section Keyword-gated provider keys (#868). #774 lists it as `pending`,
