## Contract boundaries frozen for delegation

- Slack user: classic `xoxp-` only for this debt work. Rotating `xoxe.xoxp-` and the CLI service-token surface remain separately bounded. Do not infer fixed widths or alphabet from tool rules.
- Slack app-level: `xapp-` plus the already reviewed four-section anatomy with open widths; no 97-character invariant. Sibling Slack credentials are attribution controls, not globally benign values.
- GitHub fine-grained PAT: `github_pat_` family remains distinct from `ghp_` and GitHub App credentials. The provider backs the prefix, not the 22/59 body split or a checksum.
- Stripe webhook: `whsec_` endpoint-signing role, separate from Stripe API keys, endpoint IDs, and `Stripe-Signature`. No universal body width/alphabet claim.
- Vercel: decide `vcp`, `vci`, `vca`, `vcr`, and `vck` separately from opaque legacy/unprefixed values. Prefix documentation alone cannot establish a body grammar, universal coverage, or T1 detection support.

No value in this record is a credential or derived from one; only fixture identifiers, counts, source-backed format boundaries, and digests are recorded.
